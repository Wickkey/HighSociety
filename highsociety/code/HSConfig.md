# HSConfig Documentation

## Logging Configuration

- **generic_log_path**: Path to the log file.
- **security_log_path**: Path to Security log file
- **loglevel**: Logging level (e.g., Debug, Info, Warning, Error, Critical).
- **log_format**: Format of the log messages.
- **backup_count**: Number of log files to keep before deleting during rotation.
- **max_bytes**: Maximum size of log file before rotation.

## Paths:

- **abs_root_dir**: Absolute root directory of High Society

## Game Settings:

- **game_name**: Game name to be displayed
- **game_version**: Version of Game
- **game_author**: Author of Game
- **game_description**: Game Description
- **game_starting_cash**: Starting cash allocated to each players
- **game_max_players**: Max players allowed in the game
- **game_min_players**: Min players allowed in the game
